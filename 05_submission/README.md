# 05_submission

Submission packages, one subfolder per venue.

## Structure

```
05_submission/
└── YYYY_VenueName/      (e.g., 2026_JDE, 2026_PAA)
    ├── submission.pdf
    ├── cover_letter.pdf
    └── replication_package/
```

## Rule

Each venue gets its own subfolder with the submission-ready PDF and any supplemental materials.
Final replication scripts go in `06_final_output/` not here.
